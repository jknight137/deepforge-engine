# Deepforge scope

Deepforge is a reusable voxel engine and agentic research testbed.

The implemented shared capabilities are larger coordinates, matching network
and storage formats, persistent identities and state, scripting, durable
scheduling, controller memory and authenticated external actor control.

Consuming projects provide their content, rules, models and agent policies.
Research use requires explicit task definitions, provenance and independent
evaluation. Infrastructure alone is not evidence of learned behavior, and
ordinary world execution does not depend on successful training.

Preserve the distinction between implemented APIs, focused correctness checks
and unmeasured production capacity. Keep interfaces reusable across projects.
Retain original licenses, author notices and source history when modifying the
inherited code. See the contribution guide and third-party notices.
